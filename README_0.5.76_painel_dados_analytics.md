# Apollo 0.5.76 - Painel de Dados

Amplia o modulo Painel de Dados com indicadores do plantel, sexo, especie, mutacao, linhagem/genetica, matrizes, identificacao por anilha e dados reprodutivos.

Posturas e nascimentos sao calculados a partir de `calendar_events` do usuario autenticado. Nao requer migration SQL.
