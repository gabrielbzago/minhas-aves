# Minhas Aves / Apollo — v0.4.7

Esta atualização inclui o SQL de cadastro do veterinário Kaique Pedro e correção responsiva do cabeçalho da página inicial em celulares.

## Ativação do veterinário
Leia `README_CADASTRO_VETERINARIO_KAIQUE.md`. O veterinário deve criar a conta com o e-mail fornecido e definir a própria senha. Depois, execute `supabase/cadastro_veterinario_kaique_pedro.sql` no SQL Editor do Supabase.

**Importante:** executar o SQL antes de a conta existir não cadastra o usuário; o script retorna uma mensagem explicativa. CRMV não foi incluído porque não foi fornecido.
