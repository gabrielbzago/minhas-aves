# Apollo 0.5.27 — Verso com árvore genealógica visual

- O verso do cartão dobrável foi redesenhado como árvore genealógica horizontal, inspirada na referência enviada.
- Colunas de Ave, Pais, Avós e Bisavós, com hierarquia visual e conexões entre gerações.
- Diferenciação visual discreta por sexo: azul para macho, rosa para fêmea e cor neutra para sexo não informado.
- Mantém identidade visual do criatório/Apollo, logo, genética, matriz, CTF e descendentes.
- Dados ausentes aparecem como “Não informado”, sem inventar ancestrais.
- Mantida a frente do cartão, seleção múltipla, limite de 24, layout dobrável e regras de assinatura da versão 0.5.26.
