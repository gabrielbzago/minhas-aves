# Minhas Aves v0.3.4 — Catálogo de espécies

Esta versão parte do v0.3.3 e amplia o catálogo com:
- Tico-tico — *Zonotrichia capensis*
- Tico-tico-rei — *Coryphospingus cucullatus*
- Sabiá-laranjeira — *Turdus rufiventris*
- Sabiá-do-campo — *Mimus saturninus*
- Bigodinho — *Sporophila lineola*
- Caboclinho — *Sporophila bouvreuil*
- Pássaro-preto — *Gnorimopsar chopi*

Pintassilgo — *Spinus magellanicus* já fazia parte do catálogo e foi mantido.

## Banco já existente
Execute `supabase/migration_catalogo_especies_0_3_4.sql` no SQL Editor do Supabase.

## Banco novo
O `supabase/schema.sql` também foi atualizado e já contém as novas espécies.

Nenhuma alteração de plano, limite de aves, autenticação ou cartão foi feita nesta versão.
