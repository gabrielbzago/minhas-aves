# Apollo 0.5.41 — Dashboard com distribuição do plantel

## Alterações
- Dashboard inicial com indicadores de aves cadastradas, aves ativas, plano e limite.
- Novo painel visual de distribuição por sexo com gráfico circular: fêmeas em rosa, machos em azul e sexo não definido em cinza.
- Percentuais e quantidades calculados a partir dos registros reais de aves do usuário, excluindo referências genealógicas.
- Indicador de aves ativas e barra de proporção.
- Layout responsivo para desktop, tablet e celular.
- Mantidos os atalhos e benefícios já existentes no dashboard.
